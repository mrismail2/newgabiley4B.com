📣 How Approval Works (Phase 4)

  1. Super Admin clicks Approve on a trial request
  2. A new school record is created in the schools table
  3. A School Admin user is created in Supabase Auth
  4. School Admin receives login credentials via email
  5. 30-day trial period begins automatically
  6. After 30 days, status becomes trial_expired unless upgraded
